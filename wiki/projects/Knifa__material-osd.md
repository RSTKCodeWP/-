## Ідея

This is a font for [fpv-wtf's msp-osd](https://github.com/fpv-wtf/msp-osd) using nice Material Design icons! Currently, **only Betaflight** is supported.

_З README.md, без переказу._

## Для чого

Some lovely Material Design fonts for Betaflight via wtfos/msp-osd.

## Інструкція

Нижче скопійовані розділи README про встановлення, збірку або запуск. Команди не доповнювались.

### Installation

1. Grab the latest release from the [releases page](https://github.com/Knifa/material-osd/releases).
2. Unzip all `.bin` files to the root of your goggle's SD card.
3. Enjoy!
