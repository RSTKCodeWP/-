# 🚀 MailPechkinBot - Продвинутый Telegram-бот для временной почты

Полнофункциональный Telegram-бот на Python для работы с временной почтой через **несколько провайдеров** с автоматическим переключением при сбоях.

## ✨ Основные возможности

### 📧 Работа с Email
- **Множественные провайдеры** - поддержка Mail.tm, TempMail.lol, 1SecMail
- **Автоматическое переключение** - при недоступности одного сервиса используется другой
- **Выбор провайдера** - возможность выбрать предпочитаемый сервис
- **Разные домены** - mail.tm, tempmail.lol, 1secmail.com/.org/.net
- **Управление** - удаление и создание новых адресов

### 🔐 Умные функции
- **Автоизвлечение кодов** - автоматическое распознавание кодов подтверждения
- **Автопроверка** - периодическая проверка новых писем
- **Уведомления** - автоматические уведомления о новых письмах
- **Поиск** - поиск по истории писем

### 💾 Хранение и организация
- **История** - автоматическое сохранение просмотренных писем
- **Избранное** - сохраняйте важные письма
- **Фильтрация** - поиск по отправителю, теме, содержимому

### ⚙️ Настройки
- **Гибкие настройки** - интервал автопроверки, предпочитаемый домен
- **Статистика** - детальная статистика использования
- **Админ-панель** - управление ботом и рассылки

## 🚀 Быстрый старт

### Требования

- Python 3.11 или выше
- Poetry (менеджер зависимостей)
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите Poetry (если еще не установлен):**
```bash
# Windows (PowerShell)
(Invoke-WebRequest -Uri https://install.python-poetry.org -UseBasicParsing).Content | python -

# Linux/macOS
curl -sSL https://install.python-poetry.org | python3 -
```

3. **Установите зависимости:**
```bash
poetry install
```

4. **Создайте файл `.env` на основе `.env.example`:**
```bash
copy .env.example .env  # Windows
cp .env.example .env    # Linux/macOS
```

5. **Добавьте токен бота в файл `.env`:**
```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

6. **Запустите бота:**
```bash
poetry run python bot.py
# или войдите в виртуальное окружение
poetry env activate 
python bot.py
```

## 🎮 Использование

### Управление ботом

Бот работает **полностью через кнопки** - никаких команд!

**Единственная команда:** `/start` - запуск бота и показ клавиатуры

### Кнопки управления

После запуска у вас появится постоянная клавиатура с кнопками:

- 📧 **Создать новую почту** - генерация временного email
- 📬 **Проверить почту** - просмотр входящих писем
- 📮 **Мой email** - показать текущий активный адрес
- 🗑️ **Удалить почту** - удаление текущего email
- ⚙️ **Настройки** - выбор провайдера и другие настройки
- ℹ️ **Информация** - о боте и статистика
- ❓ **Помощь** - инструкция по использованию

### Как пользоваться

1. **Создание почты** - нажмите кнопку "📧 Создать новую почту"
   - Бот автоматически выберет лучший доступный провайдер
   - Или используйте настройки для выбора конкретного сервиса
2. **Проверка писем** - нажмите "📬 Проверить почту"
3. **Чтение письма** - выберите письмо из списка (Inline-кнопки)
4. **Просмотр адреса** - нажмите "📮 Мой email"
5. **Настройки** - нажмите "⚙️ Настройки" для выбора провайдера
6. **Удаление** - нажмите "🗑️ Удалить почту" (потребуется подтверждение)

## 🌐 Поддерживаемые провайдеры

Бот использует несколько провайдеров временной почты с автоматическим переключением:

### 1. **Mail.tm** (Приоритет 1 - рекомендуется)
- 🔐 JWT авторизация для безопасности
- ⚡ Высокая надежность и стабильность
- ✅ Принимает письма от всех почтовых провайдеров
- 🌐 API: https://api.mail.tm

### 2. **TempMail.lol** (Приоритет 2)
- 🚀 Быстрый и простой сервис
- 📬 Хорошая доставляемость писем
- 🔄 Стабильная работа API
- 🌐 API: https://api.tempmail.lol

### 3. **1SecMail** (Приоритет 3)
- 📧 Простой и бесплатный сервис
- ⚠️ Может блокировать письма от Yandex и других провайдеров
- 🌐 Домены: 1secmail.com, .org, .net
- 🌐 API: https://www.1secmail.com/api/

### 🔄 Автоматическое переключение
При недоступности выбранного провайдера бот автоматически попробует использовать альтернативные сервисы по приоритету.

## ⚠️ Важные замечания

- **Безопасность:** Не используйте временные email для важной информации
- **Время жизни:** Письма хранятся ограниченное время (обычно несколько часов)
- **Публичность:** Email-адреса доступны всем, кто их знает
- **Ограничения:** Один пользователь = один активный email (старые удаляются)
- **Провайдеры:** Некоторые провайдеры (1SecMail) могут блокировать письма от Yandex
- **Рекомендация:** Используйте Mail.tm для максимальной совместимости

### На VPS (Ubuntu/Debian)

```bash
# Установка зависимостей
sudo apt update

curl -sSL https://install.python-poetry.org | python3 -

```

### Использование systemd (рекомендуется)

Создайте файл `/etc/systemd/system/mailpechkin.service`:

```ini
[Unit]
Description=MailPechkin Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/MailPechkinBot
ExecStart=/home/your_user/.local/bin/poetry run python /path/to/MailPechkinBot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запуск:
```bash
sudo systemctl daemon-reload
sudo systemctl enable mailpechkin
sudo systemctl start mailpechkin
sudo systemctl status mailpechkin
```

## 🐛 Решение проблем

### Бот не запускается

- Проверьте наличие токена в `.env` файле
- Убедитесь, что установлены все зависимости: `poetry install`
- Проверьте версию Python: `python --version` (должна быть 3.11+)
- Убедитесь, что Poetry установлен: `poetry --version`

### Не приходят письма

- Попробуйте сменить провайдер в настройках (⚙️ Настройки)
- Рекомендуется использовать Mail.tm для писем от Yandex и других популярных сервисов
- 1SecMail может блокировать письма от некоторых почтовых серверов
- Проверьте правильность email-адреса
- Подождите несколько минут и попробуйте снова
- При сбое одного провайдера бот автоматически переключится на другой

### Ошибки при работе с БД

- Проверьте права на запись в директорию бота
- Удалите файл `users.db` для пересоздания базы
