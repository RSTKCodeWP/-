# SkySweep32 Уровень Pro — Руководство по сборке платы (PCB)

> **Уровень**: 🔴 Pro (Sentinel) — Полная сборка: ESP32 + NRF24 + CC1101 + RX5808 + OLED + GPS + LoRa + SD Card  
> **Размер платы**: 120 × 80 мм, 2 слоя FR4, 1.6 мм  
> **Файлы**: `hardware/skysweep32_pro.kicad_pcb`, `hardware/enclosures/skysweep32_pro_case_*.stl`

## Порядок пайки (Рекомендуемый)

Соблюдайте эту последовательность для удобства сборки:

### Этап 1 — Сначала SMD компоненты
1. **U1 AMS1117-3.3** (SOT-223) — припаяйте к плате первым делом, пока она плоская.
2. **SMD Конденсаторы** (100nF × 6, 0805) — блокировочные ёмкости рядом с разъёмами модулей.
3. **SMD Резисторы** (R_BAT1, R_BAT2 100kΩ, R_LED 330Ω, 0805).

### Этап 2 — Выводные пассивные компоненты
4. **Электролитические конденсаторы** — C_IN (100µF), C_OUT (10µF), C_NRF24_BIG (10µF), C_RX5808 (100µF)  
   ⚠️ Следите за полярностью: **длинная ножка — это +** (плюс).

### Этап 3 — Разъёмы и гнезда
5. **Торцевые разъёмы SMA** × 4 — выровняйте их вровень с краем платы перед пайкой.
6. **Гнездо питания DC** J_PWR.
7. **Разъём аккумулятора JST-PH** J_BAT (если используется LiPo).
8. **Все разъёмы-гребёнки (female headers)** (1×4, 1×6, 2×4, 2×5) — используйте макетную плату или сами модули для выравнивания перед пайкой.
9. **Разъёмы для ESP32** (2 × 1×15, 1-й пин сверху) — **не впаивайте сам модуль**.

### Этап 4 — Выводные индикаторы
10. **Светодиод LED1** (Красный, 3мм) — плоская сторона светодиода (катод) должна быть обращена к резистору R_LED.
11. **Зуммер BZ1** — соблюдайте полярность.

### Этап 5 — Установка модулей
12. Вставьте все модули в соответствующие разъёмы (НЕ припаивая их намертво).
13. Установите **ESP32 DevKit V1** в её разъём.

## Архитектура питания

```
Разъём 5V DC (J_PWR) ───────┬──── RX5808 VCC (требует 5V!)
                            │
                       LDO AMS1117-3.3V
                            │
Линия 3.3V ─────────────────┼──── ESP32 VCC
                            ├──── NRF24L01+ VCC (+ конд. 10µF)
                            ├──── CC1101 VCC
                            ├──── OLED VCC
                            ├──── GPS VCC
                            ├──── LoRa VCC
                            └──── MicroSD VCC

LiPo (J_BAT, опционально) ── Делитель (100k + 100k) ──── GPIO36 (АЦП)
```

> ⚠️ **Пиковое потребление**: ~770мА при работе всех модулей. Используйте блок питания **не менее 5V 2A**.

## Заказ плат (PCBs)

### JLCPCB (рекомендуется, самый дешёвый вариант)
1. Откройте `hardware/skysweep32_pro.kicad_pcb` в **KiCad 6+**.
2. Перейдите в **File → Plot** → выберите формат Gerber → нажмите **Plot**.
3. Нажмите **Generate Drill Files** → OK.
4. Загрузите папку `gerber/` на [jlcpcb.com](https://jlcpcb.com).
5. Настройки: **2 layers** (2 слоя), **1.6mm**, **FR4**, покрытие **HASL или ENIG**, **Green** (Зеленая) маска.
6. Цена: около $2 за 5 плат + доставка.

## Сборка прошивки (Уровень Pro)

```bash
# В корне проекта:
pio run -e esp32dev_pro

# Или сразу загрузить в плату:
pio run -e esp32dev_pro -t upload
```

Убедитесь, что в `platformio.ini` указано:
```ini
[env:esp32dev_pro]
build_flags = -DTIER_PRO
```

## Чек-лист тестирования

После сборки проверьте всё в следующем порядке:

- [ ] **Визуальный осмотр**: отсутствие замыканий (соплей) припоя, все конденсаторы установлены с правильной полярностью.
- [ ] **Линия 5V**: измерьте напряжение 5V на выводах J_PWR перед установкой ESP32.
- [ ] **Линия 3.3V**: измерьте 3.3V на выходе LDO (U1) после подачи питания.
- [ ] **Serial Monitor**: выполните `pio device monitor` — проверьте сообщения об инициализации модулей.
- [ ] **NRF24**: в консоли должно быть `[NRF24] OK` или подобное.
- [ ] **CC1101**: в консоли должно быть `[CC1101] chip v=0x14`.
- [ ] **RX5808**: значения RSSI должны меняться при наличии источника 5.8 ГГц поблизости.
- [ ] **OLED**: должен показать стартовый экран в течение 2 секунд после включения.
- [ ] **GPS**: подождите около 60 секунд для "холодного старта" — проверьте наличие NMEA-предложений в консоли.
- [ ] **LoRa**: в консоли должно быть `[LoRa] init OK`.
- [ ] **SD-карта**: вставьте карту, отформатированную в FAT32 — в консоли должно быть `[SD] OK`.
- [ ] **Веб-дашборд**: подключитесь к Wi-Fi сети `SkySweep32` → откройте адрес `192.168.4.1` в браузере.
