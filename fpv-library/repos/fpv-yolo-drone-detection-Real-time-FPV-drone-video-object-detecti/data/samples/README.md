# Sample Data Folder

Place sample FPV/drone videos here.

Suggested filenames:

```text
sample_fpv.mp4
sample_drone_inspection.mp4
sample_ground_test.mp4
```

Recommended sources for your own portfolio:

- Your own FPV drone footage
- Lab test video
- Public-domain or permissively licensed drone footage
- Synthetic/simulation footage from AirSim, Gazebo, Isaac Sim, or Blender

Do not commit large video files unless necessary. For GitHub, use a short compressed demo video or link to a release asset.
