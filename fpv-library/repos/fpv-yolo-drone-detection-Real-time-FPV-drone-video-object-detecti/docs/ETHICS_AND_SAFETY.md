# Ethics and Safety

This repository is intended for lawful research, education, robotics, aerospace, inspection, and safety-oriented work.

## Do

- Use the project on your own footage or footage you have permission to analyze.
- Follow local drone laws and no-fly-zone rules.
- Avoid collecting personally sensitive footage when unnecessary.
- Explain model limitations clearly in demos and reports.
- Keep a human-in-the-loop for consequential decisions.

## Do Not

- Do not use this project to stalk, harass, or unlawfully identify private individuals.
- Do not use the system for unauthorized surveillance.
- Do not claim perfect accuracy or operational reliability from a simple demo.
- Do not deploy on aircraft in a way that distracts from safe piloting.

## Recommended GitHub Disclaimer

This project is a research and portfolio demonstration. It is not certified flight software, not a safety-critical autonomy system, and not a replacement for trained human judgment.
