# ЧАСТЬ I. Что РЕАЛЬНО применено (наука, привязанная к коду)

## §1. Интерполяция в пространстве — проективная геометрия «пиксель ↔ пеленг»

В проекте нет многомерной пространственной интерполяции поля. «Пространство» здесь — это
переход между плоскостью сенсора и сферой направлений через **пинхол‑модель**.

Фокус в пикселях из HFOV (`fpv/seeker/geometry.py`):

```
f_px = (W/2) / tan(HFOV/2)
```

Для сенсора FT640 (640 px): 9 мм‑линза, HFOV≈48.7° → f_px≈707; 13 мм → HFOV≈34° → f_px≈1047.
Это и есть таблица линз, которую вы задали (9 мм~48°, 13~34°, 19~23°, 25~17°, 35~12°).

Пеленг из компенсированного пикселя (`fpv/seeker/los.py`):

```
az = atan2(px_comp,  f_px)
el = atan2(-(py - cy), f_px)          # знак: цель вниз по кадру ⇒ el убывает
```

Субпиксельная «интерполяция» центроида цели — **взвешивание по интенсивности** (моменты
блоба, `fpv/seeker/blob.py`): центр = Σ(I·r)/ΣI. Это оценка положения точечного источника
точнее решётки пикселей — практическая пространственная интерполяция, которую мы используем.

**Честно:** линейная (малый угол `az≈Δx/f`) + проективная (`atan2`). Ни билинейной выборки
изображения, ни сплайнов, ни RBF в пространственном канале нет.

## §2. Продольная динамика планта (модель перехватчика)

Плант — не ракета. Боковое ускорение ограничено углом крена (`fpv/guidance/quad_sim.py`):

```
a_lat  = g · tan(θ),     θ ∈ [-θ_max, +θ_max]
θ_max = 40° ⇒ a_max = g·tan40° = 8.23 м/с² = 0.84 g
```

Отклик по крену/тангажу — **апериодическое звено первого порядка** (attitude‑lag):

```
dθ/dt = (θ_cmd - θ) / τ_att,        τ_att = 0.10 с   (полоса ~10 Гц, ANGLE‑mode)
```

Каналы (мир x=право, y=вперёд, z=вверх):

```
a_x = g·tan(roll)                      # боковое (крен)
a_y = g·tan(pitch) − c_drag·v_y        # продольное (тангаж) минус линейное сопротивление
a_z = 2·throttle·g·cos(θ_total) − g    # вертикальное (газ), гравитация вычтена
```

Интегрирование — явный Эйлер по dt (1 кГц): `v += a·dt; x += v·dt + ½a·dt²`.

## §3. Продольная динамика — форвардное (feed‑forward)

Три упреждающих (не по ошибке) канала:

1. **Гравитационное упреждение по газу** (`fpv/guidance/command_map.py`):
   при крене вертикальная тяга падает как cos(θ); чтобы держать высоту —
   `throttle_needed = 0.5 / cos(roll)`. Это классический feed‑forward.

2. **Чистое преследование как упреждение** (`bearing_rate.py`): `a = Vc·bearing` —
   команда «в сторону, где цель», не по замкнутой ошибке рейта.

3. **Смит‑предиктор (угловой lead)** — компенсация транспортной задержки контура
   (`GuidanceConfig.lead_time_s`): целимся в будущий пеленг
   `az_lead = az + az_rate·T_d`. Чисто угловой, без дальности.

## §4. Интерполяция и §5. Экстраполяция

- **Интерполяция:** экспоненциальное скользящее среднее (EMA) площади блоба в looming;
  малоугловая линейная в пеленге.
- **Экстраполяция:** это сердце фильтров. Предикт CV‑модели IMM
  (`x_{k+1}=F·x_k`, `az+=az_rate·dt`) — это экстраполяция состояния вперёд.
  Looming‑экстраполяция времени до удара `τ = A/(dA/dt)`. Мёртвое счисление
  дальности в 2‑state‑EKF: `R_{k+1}=R_k − Vc_k·dt` — экстраполяция дальности по
  **измеренной** (не предполагаемой) скорости сближения. Упреждение в midcourse:
  `t_go = R/Vc`.

## §6. Сглаживание

- **EMA** площади (looming, `fpv/seeker/looming.py`) против пиксельного шума.
- **Калман/IMM** (`fpv/seeker/imm.py`) — оптимальное сглаживание LOS‑состояния.
- **NIS‑планируемое сглаживание λ̇** (`bearing_rate.py`, по умолчанию OFF): тяжёлое EMA,
  когда инновации тихие (защита от блеска/glint), и открытие петли (α→1) при росте
  NIS или тревоге «модель неверна» — чтобы реальный манёвр не запаздывал.
- **α‑β фильтр** (g‑h) как задокументированный fallback.

## §7. Управление с предсказанием

Реализован **Смит‑предиктор** (угловой lead, §3) как компенсация задержки. Полноценного
**MPC / receding‑horizon** нет — и это честно указано: наведение — это PN‑закон + клампы,
не решение оптимизационной задачи на горизонте. См. Часть II §7 (что должно быть).

## §8. Линейная и билинейная интерполяция

- **Линейная:** EMA, малоугловое приближение, линейный blend pursuit↔PN
  (`_blend_weight`), рампа усиления PN при захвате (`acquire_settle`).
- **Билинейная:** отсутствует (нет билинейной выборки изображения в живом контуре).

## §9. Полиномиальная интерполяция

**Линейная регрессия (полином 1‑й степени)** оценки `dA/dt` в скользящем окне площади
(looming). Полиномов выше первого порядка нет.

## §10–§15. Сплайны, min‑jerk, RBF, кригинг/GPR, вейвлеты, интерполяция на сфере

Честный статус (проверено грепом по `fpv/`):

| Тема | В проекте | Что вместо этого |
|---|---|---|
| §10 Сплайновая интерполяция | **нет** | линейный blend + клампы |
| §11 Минимизация рывка (min‑jerk) | **нет** | терминальный трим‑кап 0.15·a_max (эффект «мягче», но не квинтик) |
| §12 RBF‑интерполяция | **нет** | — |
| §13 Кригинг / GPR | **нет** | — |
| §14 Вейвлет‑интерполяция | **нет** | детектор — MTI/blob, не мультимасштаб |
| §15 Интерполяция на сфере | **частично** | де‑ротация SO(2) по крену + пинхол; **не SLERP/кватернион** |

Живой канал LOS (`fpv/seeker/derotate.py`) снимает эго‑вращение малоугловой моделью:
сдвиг от гиро `ego_shift = (−f·ω_y·dt, −f·ω_x·dt)`, поворот по накопленному крену
`dx_w = dx_t·cosθ − dy_t·sinθ`. Это верно для строапдауна с умеренными углами; полноценной
сферической интерполяции ориентации (кватернионный SLERP) в живом тракте нет.

## §16. Продвинутые методы фильтрации и ML

**IMM (Interacting Multiple Model)** — ядро оценивания LOS (`fpv/seeker/imm.py`):

- Состояние `x = [az, el, aż, el̇]`, две моды: CV (низкий Q) и MANEUVER (высокий Q, Singer).
- Смешивание Бар‑Шалома (11.6.6): микс‑условия `x̄_j = Σ_i μ_{i|j}·x_i`,
  `P̄_j = Σ_i μ_{i|j}(P_i + (x_i−x̄_j)(…)ᵀ)`.
- **Коррелированное R** (важная честность): рейт — конечная разность пеленга, поэтому
  его шум ~2× и коррелирован с пеленгом:

  ```
  R_axis = [[σ²,      σ²/dt   ],
            [σ²/dt,   2σ²/dt² ]]
  ```

  Это убрало двойной учёт (раньше NIS≈2, апостериор сверхуверен).
- **dt‑дискретизированный Q** (WNA, Бар‑Шалом §6.3.2), за флагом:

  ```
  Q_axis = q_c · [[dt³/3, dt²/2],
                  [dt²/2, dt   ]]
  ```

- Обновление вероятностей мод по гауссову правдоподобию инновации (в лог‑пространстве).
- **NEES/NIS‑консистентность** как диагностика (не входит в фильтр): `nis_true` по
  инновационной ковариации S, устойчивая тревога «модель неверна» при затяжном превышении χ²‑границы.
- **Классификатор дрона** (`fpv/seeker/classify/`) с temperature‑scaling калибровкой и
  **честной метрикой безопасности** `false_grant_rate = P(grant | не‑дрон)` вместо AUC,
  плюс power‑gate, отказывающийся сертифицировать при статистически недостаточных данных.

## §17. Робастная фильтрация

Механизмы **есть** (частью за флагами по умолчанию OFF, чтобы сохранить бит‑идентичность):

- **Huber‑клип обновления состояния** IMM для «хвостовой» инновации (glint), при этом
  правдоподобие остаётся RAW, чтобы маневровая мода не «ослепла».
- **Эго‑гейт**: большая рейт‑инновация трактуется как остаток де‑ротации (не манёвр) и
  демпфирует правдоподобие маневровой моды (×0.3), пока превышение не станет затяжным
  (N кадров) — временной дискриминатор «блеск против манёвра».
- **Инфляция R** по качеству эго‑оценки и по пиксельному размеру цели.

## §18. Оценивание на скользящем горизонте (MHE)

**Отсутствует.** Дальностный канал — рекурсивный EKF, а не MHE. См. Часть II §18.

## §19. Фильтры частиц

**Отсутствуют.** Все фильтры гауссовы (KF/EKF/IMM). См. Часть II §19 — именно здесь
неоднозначность масштаба‑размера просит частиц/гауссовой суммы.

## §20. Интегрированное наведение и управление (IGC)

**Отсутствует.** Наведение (`bearing_rate`) и управление (`command_map` → плант) —
**раздельные** контуры. Честно: это классическая каскадная схема, не IGC.

## §21. Сальво / совместный перехват

**Отсутствует.** Один перехватчик. (Грепы `salvo/cooperative` — ложные срабатывания в
несвязанном коде.) См. Часть II §21.

## §22. Ключевой реально применённый закон наведения — «истинный PN» через субтензу

Базовый закон (`fpv/guidance/bearing_rate.py`):

```
a_cmd = N · Vc · λ̇          (N=3; занулитель скорости линии визирования)
```

Честная физика двух источников:
- **направление** (знак λ̇) — из IMM;
- **масштаб** Vc — исторически «расписан» (SpeedPolicy), потому что τ вырождается именно в
  трёх рабочих режимах (захват, кроссинг, удар). APN‑член **удалён** как размерно неверный
  без дальности (честно задокументировано в коде).

**Прорыв дальностного канала — субтенза по идентичности** (`fpv/seeker/subtense_range.py`).
PN‑перехватчик зануляет λ̇ ⇒ собственный параллакс `a_perp→0` ⇒ дальность становится
ненаблюдаемой ровно по мере сближения (жестокая ловушка бэрингс‑онли). Обход — не геометрией,
а **идентичностью**: у цели известного класса известен физический размер S, а её силуэт при
дальности боя **разрешён** (~11–24 px):

```
w_px = f_px · S / R          (субтенза объекта известного размера)
R    = f_px · S / w
ρ    = 1/R = w/(f_px·S)       (ЛИНЕЙНО по w, наклон H=f·S известен)
```

Честное разделение ошибки (это интеллектуальная подпись проекта):

```
σ_R,random     = R·(σ_w/w)                       ∝ R²   (белый, УСРЕДНЯЕТСЯ фильтром)
σ_R,systematic = R·√((σ_S/S)² + (σ_f/f)²)        ∝ R    (масштаб размера, НЕ усредняется)
```

Свести их в один «сжимающийся σ» было бы ложью о недостижимой пассивно точности —
поэтому `SubtenseRangeEstimate` несёт их **раздельно**.

**Наблюдаемость Vc ⇒ истинный PN.** Раз R(t) наблюдаемо каждый кадр, наблюдаема и его
производная: 2‑state EKF `[R, Vc]`, `Ṙ=−Vc`, измерение `w=f·S/R`, `H=[−w/R, 0]`,
дискретизированный WNA `Q=σ_a²·[[dt³/3,−dt²/2],[−dt²/2,dt]]`. Наведению отдаётся
**измеренная** Vc (вместо расписанной) и реальный `t_go=R/Vc`.

**Анти‑фабрикация** (ответ аудиту): 1‑state — чистое случайное блуждание (среднее НЕ
двигается на предикте; coast только растит ковариацию, никакого Vc‑дрейфа). 2‑state
дед‑реконит R, но по **своему измеренному** Vc и с честно растущей Q. Разница принципиальна:
распространять измеренное состояние с растущей неопределённостью — законно; вбрасывать
предположенное значение как известное — фабрикация.

**Разрыв неоднозначности — ToF‑самокалибровка (Ось V):** один доверенный жёсткий замер
`R_tof` откатывает истинный проектный размер `S_eff = w·R_tof/f`, коллапсируя систематику
на весь остаток полёта. ToF не на критическом пути: без него работаем на классовом приоре,
с ним — и уточняем дальность, и учим пассивный канал реальному размеру.

## §23. Midcourse с большим запасом — «будто баллистический»

Реализовано (`fpv/guidance/midcourse.py`, доказано замкнутым тестом). Физика доктрины:

```
R_turn = Vi² / (g·tan θ_max) ≈ 150²/8.23 ≈ 2734 м  ≫  дальность боя 50–200 м
```

⇒ в терминале перехватчик **почти баллистичен** — довернуть в последние доли секунды нельзя.
Значит упреждение ставится в midcourse. g‑стена и запас:

```
λ̇_wall = a_max/(N·Vc)                  (рейт, где требование PN = предел планера)
margin  = λ̇_wall / |λ̇|,   established = margin ≥ 3   (3:1 overmatch)
```

Фазы: MIDCOURSE (полная a_max, ставим лид) → BALLISTIC_TERMINAL (лид с запасом ⇒ трим
≤0.15·a_max) → TERMINAL_BEST_EFFORT (лид не добран ⇒ **честный** флаг, дожим). Замкнутый
детерминированный тест: margin 0.99→2.7→22→478, лид установлен **в MIDCOURSE**, терминал
баллистичен (λ̇≈0), промах < 5 м.

# ЧАСТЬ II. Что ДОЛЖНО быть применено, чтобы наука стала лучшей в мире

Разделяю честно: **настоящий рычаг** (двигает TRL/точность/физику) против
**представление/косметика** (приятно, но не решает физическую стену).

### Настоящие рычаги (в порядке отдачи для ЭТОГО проекта)

**§19 → Фильтр частиц / гауссова сумма для неоднозначности масштаба‑размера.**
Честная «одна ловушка» субтензы — `w=f·S·ρ`: одно уравнение, два неизвестных (S и ρ).
Гауссов EKF прячет это в систематический член. Математически честное представление —
**смесь по гипотезам класса**: частицы/GSF над `{класс_i (⇒ S_i, приор p_i) × ρ}`.
Тогда неопределённость размера **маргинализуется** байесовски, а не приклеивается сбоку;
мультимодальность на захвате (несколько классов‑кандидатов) представлена честно. Это
прямое, некостыльное улучшение самой честной части проекта. **Рычаг: высокий.**

**§15 → Кватернионный строапдаун (SLERP) + EKF смещения гиро (MEKF).**
Живая де‑ротация — малоугловая SO(2) по крену. Доминирующая реальная ошибка строапдауна —
скос синхронизации cam↔IMU и масштаб/смещение гироскопа (наука проекта прямо называет это
верхним неизмеренным членом). Правильно: интегрировать ориентацию на SO(3) кватернионами,
оценивать смещение гиро мультипликативным EKF, LOS вести на сфере. **Рычаг: высокий** —
при больших эволюциях планера это и есть разница между попаданием и промахом.

**§18 → MHE для канала `[R, Vc]`.** У окна измерений субтензы + жёстких ограничений
(`Vc≥0` у терминала, `R>0`, `w>0`) оценка на скользящем горизонте бьёт рекурсивный EKF в
сильно нелинейном околоударном режиме и естественно робастна к выбросам (glint). **Рычаг:
высокий** для терминала.

**§17 → Полноценная робастная/H∞ (или Стьюдент‑t) фильтрация.** Huber есть, но выключен.
На реальном Y16 (блеск, солнечные блики, тепловой клаттер) тяжёлые хвосты — норма; робастный
IMM с t‑распределением инноваций — обязательный, не опциональный. **Рычаг: высокий** и дешёвый.

**§7/§20 → MPC + IGC (управление у края конверта).** Заменить PN+клампы коротким‑горизонтным
MPC, который **явно** уважает g‑стену и attitude‑lag τ; и слить наведение с автопилотом
(IGC), убрав задержечный промах `miss ~ N·Vc·T_d²·a_T/2`. Для малого лаг‑доминируемого
планера это реальный выигрыш. **Рычаг: высокий, но тяжёлый** (нужна модель планта в контуре).

**§21 → Сальво / кооперативный перехват (time‑to‑go consensus).** Честный ответ на цель,

маскирует её).

# ЧАСТЬ III. Научное открытие проекта

## «Наблюдаемость по идентичности замыкает парадокс наблюдаемости пропорционального наведения для пассивного строапдаун‑перехватчика»

**Парадокс (известная стена).** Бэрингс‑онли наблюдатель делает дальность наблюдаемой только
через собственный манёвр (параллакс): информационная матрица Фишера вырождена к дальности при
прямолинейном движении. Но закон PN **зануляет** скорость линии визирования, а значит
`a_perp→0` — тот самый параллакс исчезает **ровно в терминале, по мере сближения**. Итог:
пассивный PN‑перехватчик слеп по дальности именно тогда, когда дальность нужнее всего. Это не
инженерный недочёт, это структурное свойство связки «PN × пассивный монокуляр».

**Открытие.** Заменить геометрическую наблюдаемость **наблюдаемостью по идентичности**. Как
только класс подтверждён (а значит известен физический размер S), разрешённая субтенза даёт

```
ρ = w/(f·S)
```

— **линейное, покадровое, абсолютное** измерение обратной дальности, **независимое от
собственного манёвра**, с математически строгим разделением ошибки на белую (∝R², усредняемую)
и систематическую масштабную (∝R, неусредняемую). Это делает `Vc=−dR/dt` наблюдаемой ⇒
«истинный PN» (измеренная Vc вместо расписанной), а единичный возврат ToF самокалибрует S
(`S_eff=w·R_tof/f`), коллапсируя систематику на весь полёт.

**Замыкание архитектуры.** В связке с доктриной «запас в midcourse, терминал баллистичен»
(`R_turn≫R_engage` ⇒ лид ставится ×3 в midcourse, терминал только тримит) получается
**полная, внутренне честная** архитектура терминального наведения строапдаун‑ГСН, в которой
каждый ненаблюдаемый параметр либо измерен по идентичности, либо явно помечен как
предположение с растущей ковариацией.

**Новизна, честно ограниченная.** Субтенза известного размера — не новость сама по себе
(оптические дальномеры, ГСН по угловому размеру). Новизна — в **связке**: (a) явная
формулировка PN‑парадокса наблюдаемости как причины смерти параллакса именно у терминала;
(b) идентичность как замена геометрии ровно в этом мёртвом окне; (c) дисциплина
random/systematic‑разделения, запрещающая фильтру рапортовать недостижимую пассивно точность;
(d) ToF как самокалибратор размера, а не как костыль на критическом пути; (e) доктрина
«баллистического запаса», следующая из соотношения радиуса разворота к дальности боя.
Это **уровень готовности TRL 3–4**, доказано в симуляции, не валидировано на реальных Y16,
одноцелевое. Честная научная заявка — «непротиворечивая архитектура и метод», а не «доказанное
оружие».

## V.1. Квинтический сплайн / минимизация рывка (§10–§11)

Опорная команда крена сейчас — жёсткий клампованный PN‑выход, проходящий через attitude‑lag.
При резкой смене знака λ̇ у насыщения это рывок, возбуждающий упругие моды. Профиль **минимума
рывка** (Flash–Hogan) минимизирует `∫₀ᵀ (d³s/dt³)² dt`. Для перехода rest‑to‑rest:

```
s(τ) = s₀ + (s_f − s₀)(10τ³ − 15τ⁴ + 6τ⁵),   τ = t/T          ✓ (s,ṡ,s̈ на концах верны)
```

Общий квинтик через 6 граничных условий (угол, скорость, ускорение на обоих концах):

```
s(t) = s₀ + v₀t + ½a₀t² + a₃t³ + a₄t⁴ + a₅t⁵
a₃ = ( 20Δ − (8v_f+12v₀)T − (3a₀−a_f)T² ) / (2T³)
a₄ = (−30Δ + (14v_f+16v₀)T + (3a₀−2a_f)T²) / (2T⁴)
a₅ = ( 12Δ − 6(v_f+v₀)T + (a_f−a₀)T² ) / (2T⁵),   Δ = s_f − s₀
```

**Применимость: умеренно.** attitude‑lag τ=0.1 с уже действует как сглаживающий фильтр 1‑го
порядка. Реальная отдача — только у насыщения привода на переходе midcourse→terminal, как
**опциональный опорный профиль**, и то если проявятся упругие моды планера. Не прорыв.

## V.2. RBF‑интерполяция и её связь с текущим центроидом (§12)

Ключевое наблюдение рецензии верно: взвешенный по интенсивности центроид
`c = Σᵢ I(xᵢ)·xᵢ / Σᵢ I(xᵢ)` — это **ядерный оценщик Надарая–Уотсона** с интенсивностью как
ядром. Явный RBF‑интерполянт обобщает его:

```
s(x) = Σᵢ wᵢ φ(‖x − xᵢ‖) + p(x),   при условии ортогональности  Σᵢ wᵢ q(xᵢ) = 0  ∀ q∈Π_m
φ: гаусс exp(−(εr)²) | мультиквадрик √(1+(εr)²) | thin‑plate r²·ln r
```

Адаптивная ширина `ε = ε(размер блоба)` даёт робастную оценку центра при неравномерной засветке
и битых пикселях без замены детектора.

**Применимость: умеренно (перцепция).** Текущий моментный центроид уже почти оптимален для
симметричного блоба; RBF окупается на **реальном Y16** с битыми пикселями и асимметричным
тепловым ореолом. Живёт во фронт‑энде, дальность/наведение не трогает.

## V.3. Вейвлет‑денойзинг Y16 (§14)

Кратномасштабное пороговое шумоподавление перед blob‑детекцией:

```
f̂ = Σ_{j,k} η_T(⟨f, ψ_{j,k}⟩) ψ_{j,k},   η_T(x)=sign(x)·max(|x|−T, 0)  (soft‑threshold)
T = σ√(2 ln N)  (универсальный порог Донохо–Джонстона),  σ = MAD(коэфф. финального масштаба)/0.6745
```

**Применимость: умеренно (перцепция).** Поднимает SNR слабой малой цели на реальном шуме без
переделки конвейера. Классика, дёшево — но это про детект, не про физику наведения.

## V.4. Кригинг / GPR для карты экстента силуэта (§13) — прямое усиление субтензы

Здесь рецензия права, что это **больше чем представление**. Если появится зависимость видимого
размера от ракурса (форшортенинг), GP‑регрессия `f: ракурс → проектный_размер S(aspect)`:

```
f ~ GP(m(x), k(x,x'))
μ*(x*)   = k*ᵀ(K + σ²I)⁻¹ y
σ²*(x*)  = k(x*,x*) − k*ᵀ(K + σ²I)⁻¹ k*
```

Ключ: предиктивная дисперсия `σ²*` — **честная неопределённость размера**, которая
подаётся прямо в систематический член субтензы `σ_S = σ*`. То есть GPR закрывает ровно ту
дыру, где сейчас стоит фиксированный классовый приор S.

**Применимость: рычаг (умеренный).** Как только моделируется ракурс — GPR даёт и интерполяцию
S(aspect), и её неопределённость для канала дальности. Прямое, некостыльное усиление §22.

## V.5. Интерполяция на сфере: SO(3), кватернионная кинематика, SLERP, MEKF (§15)

Рецензия абсолютно права: это **фундамент**, не представление. Живая де‑ротация — SO(2) по крену;
доминирующая реальная ошибка (скос cam↔IMU, масштаб/смещение гиро) требует SO(3).

```
Кинематика:   q̇ = ½ · Ω(ω) · q = ½ · q ⊗ (0, ω)
SLERP:        q(τ) = sin((1−τ)θ)/sinθ · q₀ + sin(τθ)/sinθ · q₁,   θ = arccos(q₀·q₁)
LOS в инерц.: r_LOS^inert = R(q)ᵀ · r_cam
```

**Мультипликативный EKF (MEKF)** — правильный способ оценивать смещение гиро в касательном
пространстве so(3) (ошибка живёт на многообразии, не в «плоских» углах):

```
модель гиро:  ω = ω_meas − b − n_g,   ḃ = n_b          (смещение — случайное блуждание)
ошибка‑состояние δx = [δθ, δb] ∈ ℝ⁶,  δq ≈ [1, ½δθ]
δθ̇ = −[ω]_× δθ − δb − n_g,   δḃ = n_b   (линеаризация на so(3))
```

**Применимость: РЫЧАГ (высокий).** Это и есть измерение/парирование «верхнего неизмеренного
члена» (скос синхронизации), который наука проекта называет №1. При больших эволюциях планера —
разница между попаданием и промахом. Обязательно на пути к TRL 5.

## V.6. Робастная фильтрация: Student‑t, H∞, дифференциальная игра (§17)

Huber есть, но это лишь клип. Три недостающих уровня:

**(а) Калман со Student‑t инновацией** — естественный учёт тяжёлых хвостов теплового шума/glint.
Вариационная форма через латентный масштаб `λ ~ Gamma(ν/2, ν/2)`, `z|x,λ ~ N(Hx, R/λ)`:

```
E‑шаг:  E[λ_k] = (ν + d_z) / (ν + δ_k²),   δ_k² = инновационное расстояние Махаланобиса
M‑шаг:  калмановский апдейт с R_eff = R / E[λ_k]   (выброс ⇒ E[λ]↓ ⇒ R↑ ⇒ вес↓)
```

Это строго обобщает Huber (мягкое, а не срезанное подавление) и оценивает ν по данным.

**(б) H∞‑фильтр** — минимаксный, когда модель шума неизвестна; гарантирует верхний предел
`sup ‖ошибка‖²/‖возмущение‖² < γ²`:

```
K = P[ I − γ⁻²S·P + HᵀR⁻¹H·P ]⁻¹ HᵀR⁻¹,  при [ · ] ≻ 0
γ → ∞  ⇒  K → калмановское  ✓ (проверено: K_H∞→0.80 = K_KF; при γ=2 K=0.89, агрессивнее/робастнее)
```

**(в) Игровая (дифференциальная игра)** — цель **сознательно** максимизирует ошибку оценивания
(манёвр уклонения + срыв ГСН): седловая точка `min_x̂ max_{w,v,манёвр} J` при неполной информации.
H∞ — её частный (линейно‑квадратичный) случай.

**Применимость: РЫЧАГ (высокий), дёшево.** Для Y16 рекомендация — **Student‑t IMM** (лучший
баланс: гладкое подавление, оценка ν, совместимость с текущим гауссовым трактом); H∞ — как
страховка при активных помехах; игровая постановка — теоретическая рамка ECCM.

## V.7. MHE — оценивание на скользящем горизонте (§18)

Для канала `[R, Vc]` MHE решает на окне длины N с **физическими ограничениями**:

```
min_{x_{k−N..k}}  Γ(x_{k−N}) + Σ_{i=k−N}^{k} ‖z_i − h(x_i)‖²_{R⁻¹} + Σ ‖x_{i+1} − f(x_i)‖²_{Q⁻¹}
s.t.   R_i > 0,   Vc_i ≥ 0 (у терминала),   w_i > 0
Γ(·) — arrival cost, аппроксимируется из ковариации EKF (сшивка с рекурсивным фильтром)
```

**Применимость: РЫЧАГ (высокий) у терминала.** Именно там EKF `w=f·S/R` склонен расходиться
(H=−w/R² растёт при R→0), а ограничения `Vc≥0, R>0` и оконная робастность к glint — то, чего
рекурсивная форма не даёт.

## V.8. Фильтры частиц / RBPF для неоднозначности масштаб‑размер (§19)

Самая честная возможность: представить неоднозначность `w = f·S·ρ` (одно уравнение, два
неизвестных) как **байесовскую смесь по классам**, а не приклеенный систематический член:

```
p(ρ, S, c | w_{1:t}) ∝ p(c)·p(ρ)·∏_t p(w_t | ρ, S_c)
Rao‑Blackwell: частицы над дискретным классом c (⇒ S_c), аналитический KF по линейному ρ|c
вес частицы:  w^(i) ∝ p(w_t | w_{1:t−1}, c^(i))  (правдоподобие инновации KF данной гипотезы)
```

Апостериор **до ToF** — мультимодальный по классам (несколько S‑гипотез, каждая со своим R);
**после ToF** `S_eff=w·R_tof/f` коллапсирует в одну моду, согласную с жёстким замером. Так
систематика **маргинализуется**, а не прячется сбоку.

**Применимость: РЫЧАГ (высокий).** Прямой ответ на «одну честную ловушку» §22. Математически
корректное представление неопределённости размера; следующий логичный модуль реализации.

## V.9. IGC: backstepping + барьерная функция Ляпунова для FOV (§20)

Каскад «наведение → управление» теряет на лаге привода τ=0.1 с (задержечный промах
`~N·Vc·T_d²·a_T/2`). IGC сливает их в один нелинейный контроллер. Синтез backstepping:

```
z₁ = λ̇  (хотим → 0);  виртуальное управление a_des = −k₁·(N·Vc)⁻¹·z₁ … (требуемое ускорение)
z₂ = a − a_des;  реальный закон по крену через lag  τ·θ̇ = θ_cmd − θ  гонит z₂ → 0
Ляпунов: V = ½z₁² + ½z₂²,  V̇ = −k₁z₁² − k₂z₂² < 0   (учитывает динамику привода явно)
```

**Барьерная функция Ляпунова для удержания цели в поле зрения ГСН** (вообще не затронуто в проекте):

```
V_b = ½·ln( δ² / (δ² − ε²) ),   ε = ошибка от боресайта,  δ = предел FOV/2
V_b → ∞ при ε → δ  ⇒  закон управления не выпускает цель за край FOV
```

**Применимость: РЫЧАГ (высокий, тяжёлый).** Для лаг‑доминируемого малого планера IGC реально
режет промах; барьерная FOV‑функция закрывает риск срыва захвата у края поля зрения строапдауна.
Требует модель планта в контуре — это существенная работа.

## V.10. Сальво / кооперативный перехват: консенсус по t_go / ITCG (§21)

Против цели, переигрывающей одиночное тело 0.84 g — несколько перехватчиков, согласующих время
до удара. Управление по времени удара (ITCG) + консенсус:

```
a_M = a_PN + a_shaping,   a_shaping гонит t_go к общему t_d  (impact‑time control, Jeon 2006)
протокол консенсуса:  u_i = −Σ_j a_ij · (t_go,i − t_go,j)   (граф связи a_ij)  ⇒  t_go,i → общий
```

**Применимость: стратегический рычаг.** Снимает физическую стену манёвренной цели (охват
конверта), а не маскирует её. Требует ≥2 планеров и линка — программа, не патч.

# ЧАСТЬ VI. Упущенные научные подобласти

## VI.1. Информационная геометрия и наблюдаемость (строгий фундамент §22)

Это то, чего не хватало моему «открытию» — формальный аппарат. Три инструмента:

**Информация Фишера для дальности (bearings‑only).** Для пеленговых измерений `β_i`:

```
J_RR = Σ_i (∂β_i/∂R)² / σ_β²
```

Для непрямоманеврирующего носителя информация о дальности вдоль LOS обнуляется; она набирается
только боковым разносом от собственного манёвра `a_perp`. Под PN (`λ̇→0 ⇒ a_perp→0`):
`J_RR → 0 ⇒ CRLB_R = J_RR⁻¹ → ∞`. **Это формальная запись парадокса наблюдаемости PN.**

**Нелинейная наблюдаемость (Эрман–Кренер).** Система наблюдаема, если кораспределение
`dO = span{dh, dL_f h, dL_f² h, …}` имеет ранг n. При bearings‑only h и CV‑динамике направление
R входит лишь через высшие производные Ли, зануляющиеся без `a_perp` — ранг падает. С субтензным
измерением `h = f·S/R` градиент **прямо** содержит R: `∂h/∂R = −f·S/R² ≠ 0` — ранг восстановлен
за один шаг. Это строго доказывает, **почему** идентичность возвращает наблюдаемость.

**Байесовская CRLB (ван Трис) — формальный вывод random/systematic.** Размер S — мешающий
параметр с приором `σ_S`. Байесовская информация `J_B = E[J_data(θ)] + J_prior`, где
`J_prior` от приора размера ставит пол, который **никакие данные не пробивают**:

```
Var(R)/R² ≥ (σ_S/S)² + (σ_f/f)²          ⇒   σ_R,systematic = R·√((σ_S/S)²+(σ_f/f)²)
```

✓ Проверено численно: при S=4 м, σ_S=0.4 м, R=150 м пол `σ_R = 15.0 м` = ровно систематический
член §22. **То есть мой random/systematic‑раскол — не эвристика, а байесовская граница Крамера‑Рао
для смешанной ошибки.** Random‑часть — усредняемая (data‑информация ∝ число кадров), systematic —
неусреднимый приорный пол. ToF добавляет прямую информацию о S, опуская пол.

## VI.2. Байесовское ML для гетероскедастической неопределённости

Вместо фиксированного R в IMM — сеть, предсказывающая **и пеленг, и его дисперсию** из сырого кропа:

```
выход:  (β̂, log σ²_β(crop))       — алеаторная (гетероскедастичная) неопределённость
MC‑Dropout / байесовская NN:  σ²_epistemic = Var по T стохастическим прогонам
подача в фильтр:  R_frame ← σ²_β(crop) покадрово  (динамически адаптивный R)
```

**Применимость: рычаг (перцепция→фильтр).** Замыкает восприятие и оценивание: блеклый/
пересвеченный кадр сам сообщает фильтру «не верь мне». Требует данных Y16.

## VI.3. Обнаружение разладки (change‑point) для «блеск vs манёвр»

Текущий дискриминатор — эвристический счётчик затяжности. Формально:

```
CUSUM:   S_k = max(0, S_{k−1} + ℓ_k − drift),  ℓ_k = log‑ПО «манёвр/блеск»;  тревога при S_k > h
BOCPD:   апостериор длины прогона p(r_k | z_{1:k}) — байесовский он‑лайн детектор точки разладки
```

**Применимость: рычаг (умеренный).** Заменяет `n_sustain`‑эвристику принципиальным тестом с
контролируемой вероятностью ложной тревоги — прямое усиление эго‑гейта IMM.

## VI.4. Планирование в пространстве убеждений (belief‑space / POMDP)

Доктрина midcourse — рукотворная эвристика. Строго это стохастическое оптимальное управление:

```
POMDP:  π* = argmin_π E[ miss² ]  над политиками π(belief),  belief = p(x | z_{1:k})
решение: iLQG/belief‑iLQR — неопределённость СОСТОЯНИЯ явно влияет на стратегию (information‑seeking)
```

Тогда «запас ×3 в midcourse» вышел бы **из** минимизации ожидаемого промаха, а не задавался руками.

**Применимость: рычаг (тяжёлый, исследовательский).** Правильная общая рамка; доктрина —
её дешёвое приближение. Оправдано, когда неопределённость дальности велика и манёвренна.

## VI.5. Формальная верификация критических подсистем

Для перехода к сертифицируемости (DO‑178C ПО / DO‑254 сложное железо):

- **Model checking цепочки миссии.** Свойство безопасности в темпоральной логике:
  `AG( kinetic_release → committed ∧ handoff_valid ∧ hash_match )` — доказуемо на конечном
  автомате `mission_fsm.py` (нет пути к релизу без commit+валидный handoff+совпадение хэша).
- **Абстрактная интерпретация** кода фильтров — доказательство отсутствия переполнений/NaN,
  границ численных диапазонов (усиливает уже существующие NaN‑fail‑safe в `bearing_rate.py`).

**Применимость: рычаг для сертификации.** Не улучшает точность, но необходимо для TRL 6+.

## VI.6. Дифференциальная геометрия строапдауна (группы Ли)

Формальная основа V.5: интегрирование на SO(3)/SE(3), уравнения ошибки MEKF в касательном
пространстве so(3), экспоненциальное/логарифмическое отображение `Exp: so(3)→SO(3)`, якобианы
SLERP и правого якобиана группы для ковариации на многообразии. **В проекте отсутствует полностью.**
Это язык, на котором пишется корректный строапдаун‑наблюдатель (не «плоские» углы Эйлера).

**Применимость: фундамент (высокий).** Идёт в комплекте с V.5; без него MEKF математически неаккуратен.

## VI.7. Квантовые / нейроморфные вычисления (перспектива — честно спекулятивно)

Долгосрочно: MPC/оптимизация на квантовых отжигателях; сверхбыстрое распознавание/λ̇ на
нейроморфных чипах (event‑камера + spiking‑сеть — это уже перекликается с event‑channel проекта).
**Применимость: перспектива.** Честно помечаю как спекулятивное, не путь ближайшего TRL.
