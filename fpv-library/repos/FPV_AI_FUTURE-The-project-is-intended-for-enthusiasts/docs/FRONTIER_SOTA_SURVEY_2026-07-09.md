## §1. Наведение и «трек‑ту‑интерцепт» (теория управления + теория наведения + ракетодинамика)

### 1.1. Классика остаётся квазиоптимальной, но её переосмысляют через ZEM

Пропорциональная навигация (PN) формально **квазиоптимальна** для перехвата: команда зануляет
**Zero‑Effort‑Miss (ZEM)** за конечное время. Современная формулировка выражает закон не через
«N·Vc·λ̇», а через ZEM‑нуллинг:

```
ZEM = промах, если оба продолжат по инерции;   a_cmd = N · ZEM / t_go²
(эквивалентно N·Vc·λ̇ в пределе малых углов — но ZEM‑форма прямо ест t_go и упреждение манёвра)
```

Это тот же наш `a=N·Vc·λ̇`, но ZEM‑запись естественно принимает измеренный `t_go` (наш канал
субтензы даёт его!) и APN‑поправку на манёвр. **Прямой апгрейд нашего закона: переписать PN в
ZEM/t_go‑форме, куда честно входит измеренная Vc.**

### 1.2. Deep‑RL и мета‑обучение guidance‑законов (2021–2025)

Свежая линия: **DRL‑законы наведения**, превосходящие TPN против высокоманёвренных целей **с
учётом ограничения поля зрения ГСН** (FOV‑limit) — ровно наша строапдаун‑проблема. Приёмы:
- **Prediction‑correction**: NN супервизорно оценивает `t_go` под PN, RL добавляет смещённую
  команду для управления временем удара (impact‑time).
- **Reinforcement meta‑learning** для политики кривизны линии визирования (PN‑LOSC) — искривлённый
  LOS + PN, робастнее к вариациям модели контроллера.
- **Assisted DRL** для head‑on перехвата манёвренной цели.

**Релевантность:** DRL даёт **робастность к неопределённости модели** (наш attitude‑lag,
задержки), но требует симулятора и валидации; ближайший честный шаг — не заменять PN, а
**обучать поправку** поверх аналитического PN (residual‑RL), сохраняя доказуемое ядро.
Источники: [AIAA JAIS: Computational Missile Guidance DRL](https://arc.aiaa.org/doi/10.2514/1.I010970),
[Springer: assisted DRL head‑on maneuvering](https://link.springer.com/article/10.1007/s40747-021-00577-6),
[arXiv: RL meta‑learning LOS curvature](https://arxiv.org/pdf/2205.00085),
[arXiv: computational impact‑time guidance](https://arxiv.org/pdf/2103.05196).

### 1.3. Интегрированное наведение и управление (IGC) — прямое подтверждение нашей V.9

Поиск нашёл **именно** то, что я рекомендовал: **IGC для строапдаун‑ракеты с ограничением поля
зрения через интегральную барьерную функцию Ляпунова (iBLF)**, в связке backstepping + скользящий
режим (SMC) + dynamic surface control (DSC) + расширенный наблюдатель состояния (ESO):

```
Каскад «наведение→управление» сливается в один нелинейный контроллер;
iBLF:  V_b = ½·∫ ... ln( δ²/(δ²−ε²) )  удерживает цель в FOV строапдауна (ε<δ гарантированно);
ESO оценивает возмущение (манёвр цели) без его измерения; SMC/DSC парируют лаг привода.
```

**Релевантность: высокая, подтверждена литературой.** Это дорожная карта нашего V.9 —
строапдаун + FOV + лаг привода — в готовом научном виде. Источники:
[iBLF IGC strapdown FOV](https://researchgate.net/publication/348462687_Integral_barrier_Lyapunov_functions-based_integrated_guidance_and_control_design_for_strap-down_missile_with_field-of-view_constraint),
[Wiley RNC 2024: full‑state‑constrained IGC tunnel‑prescribed](https://onlinelibrary.wiley.com/doi/10.1002/rnc.7384),
[SAGE 2025: partial‑state‑constrained IGC STT](https://journals.sagepub.com/doi/10.1177/01423312241282752),
[MDPI Aerospace: FOV‑constrained IGC hypersonic](https://doi.org/10.3390/aerospace9110640).

### 1.4. Кооперативное/сальво (подтверждение V.10)

Импакт‑тайм управление + консенсус `t_go`, теперь и как **MARL** (MAPPO, централизованный критик
/ децентрализованное исполнение) для контр‑БПЛА роёв. Источники:
[MDPI: cooperative counter‑drone swarms MADRL](https://doi.org/10.3390/engproc2026133164),
[arXiv: RL interception prioritization drone‑swarm defense](https://arxiv.org/html/2508.00641v1),
[IEEE WirelessComm: Counter‑UAV swarms directions](https://dl.acm.org/doi/10.1109/MWC.003.2400047).

## §2. Расчёт траектории цели (оценивание + прикладная математика)

### 2.1. IMM жив, но обрастает нейросетями

Наш IMM — крепкий базис. Фронтир движется к гибридам:
- **Transformer‑трекеры манёвренных целей (TrMTT)** — attention по истории состояния бьёт
  чистый IMM на сильном манёвре (radar tracking, Information Fusion).
- **IMM+RNN / Autoencoder‑IMM** — обучаемое переключение мод и модели процесса.
- **IMM‑behavior‑guided multi‑model** для высокоманёвренных **воздушных** целей (2026) — прямо
  наш класс цели.

### 2.2. Диффузионные предсказатели — мультимодальность и честная неопределённость

Самое интересное для нашей «честности неопределённости»: **диффузионные модели траектории**
дают **мультимодальную** апостериорную плотность будущего с калиброванной неопределённостью;
быстрый семплинг **DDIM** (×100 ускорение) → аппроксимация **GMM** для трактуемости; есть
**гетероскедастичные** диффузии (шум зависит от контекста). Это концептуальный родственник моего
предложения о **частицах/GSF** (Часть V.8 научного доклада): и там, и там — мультимодальная
плотность вместо одной гауссианы.

**Релевантность:** на нашем железе полная диффузия дорога, но **идея мультимодальности +
гетероскедастичности** — правильный вектор для канала манёвра/размера; дешёвый суррогат — GSF/RBPF.
Источники:
[Information Fusion: transformer maneuvering target tracking](https://dl.acm.org/doi/10.1016/j.inffus.2023.102120),
[Springer 2026: IMM behavior‑guided multi‑model aerial](https://link.springer.com/article/10.1007/s42452-026-08398-3),
[arXiv 2410.03860: multimodal diffusion motion + uncertainty](https://arxiv.org/abs/2410.03860),
[arXiv 2602.21319: uncertainty‑aware diffusion DDIM→GMM](https://arxiv.org/abs/2602.21319),
[arXiv 2605.10717: heteroscedastic diffusion](https://arxiv.org/pdf/2605.10717).

### 3.2. Дискриминация «цель vs ловушка» (контр‑ИК‑меры)

Как современные imaging‑ГСН отличают цель от помехи (нам это нужно для honest‑классификатора):
- **Imaging‑дискриминация**: локальный точечный источник (флаер) против **распределённого**

## §5. Позиционирование / инерциальная навигация (дифференциальная геометрия + БИНС)

Прямое подтверждение моих V.5/VI.6: современный строапдаун **не** живёт в углах Эйлера.

- **Инвариантный EKF (InEKF)** ставит навигационное состояние на **матричную группу Ли SE₂(3)**
  и использует **group‑affine** симметрию: якобианы распространения **не зависят от траектории** →
  радикально лучшая **консистентность** оценки (то, за чем мы гоняемся в NEES/NIS!).
- **Deep‑inertial odometry**: обучаемая оценка forward‑speed из IMU + неголономное ограничение
  (NHC) как измерение в строапдаун‑каркасе, слитые InEKF.
- **Factor‑graph optimization**: бесшовная фьюжн IMU‑ и exteroceptive‑резидуалов (сглаживание на
  окне — родня MHE из моего доклада).

**Релевантность: высокая.** Наш ego‑motion/де‑ротация должны мигрировать на **InEKF/MEKF на
SO(3)** с оценкой смещения гиро — это и есть измерение «верхнего неизмеренного члена» (скос
cam↔IMU). InEKF‑консистентность прямо лечит нашу «консервативность» фильтра. Источники:
[ISPRS 2024: InEKF pedestrian deep‑inertial odometry](https://isprs-archives.copernicus.org/articles/XLVIII-4-2024/607/2024/isprs-archives-XLVIII-4-2024-607-2024.pdf),
[IEEE TITS: robust VIO Kalman + factor graph](https://dl.acm.org/doi/abs/10.1109/TITS.2023.3258526),
[arXiv 2311.07049: Clifford‑algebra IEKF INS/GNSS](https://arxiv.org/pdf/2311.07049).

## §6. Физика сенсора (ИК‑фотоника + квантовая электроника + теплофизика)

### 6.1. Охлаждаемый MWIR против неохлаждаемого LWIR — наш выбор в контексте

- **Охлаждаемые MWIR** (InSb, T2SL) с **unipolar‑barrier nBn/XBn** структурами: барьер подавляет
  деплеционный тёмный ток → высокая чувствительность (ΔT ~0.01 °C), но нужен криоохладитель
  Стирлинга до ~77 K → тяжёлая цена по SWaP.
- **Неохлаждаемые LWIR микроболометры**: резко меньше размер/цена/энергия → **естественный
  кандидат для коротко/средне‑дальних ГСН** (это дословно про наш класс).
- **HOT‑детекторы** (High Operating Temperature) — снижают бремя охлаждения, улучшают SWaP.
- **QWIP** — для ~10 мкм, униполярный транспорт, очень высокие частоты отклика.

**Релевантность: фундаментальная и подтверждающая.** Наш **FT640 = неохлаждаемый LWIR‑микроболометр**
— ровно то, что литература называет естественным выбором для нашего класса. Цена честности:
чувствительность и дальность детекта ниже охлаждаемого MWIR; тепловой NETD‑шум выше — отсюда
важность денойзинга (вейвлет из доклада) и робастной фильтрации. Источники:
[SCD: cooled & uncooled IR detectors for missile seekers](https://scdusa-ir.com/articles/cooled-and-uncooled-infrared-detectors-for-missile-seekers/),
[IRCameras: HOT IR sensors improve SWaP](https://ircameras.com/advances-in-detectors-hot-ir-sensors-improve-ir-camera-size-weight-and-power/),
[LightPath: LWIR vs MWIR](https://www.lightpath.com/blog/making-the-right-choice-lwir-vs-mwir-for-your-thermal-imaging-strategy),
[arXiv 2511.03868: mid‑IR semiconductor photonics roadmap](https://arxiv.org/pdf/2511.03868).

### 6.2. Атмосферная оптика и окна прозрачности

Работаем в окне **LWIR 8–12 мкм** (наш микроболометр); ослабление/рассеяние в тумане/дыму/пыли
задаёт бюджет дальности детекта (наука проекта: детект ~115–190 м). MWIR 3–5 мкм — вторая полоса.
Это теплофизика+атмосферная оптика, определяющая `SNR(range)`.

### 6.3. Event‑камеры / нейроморфика — перекликается с нашим `event_channel.py`

- **μs‑латентность**, динамический диапазон **120–140 дБ** (от звёздного света до солнца),
  событие `(x,y,t,p)` при пороговом изменении лог‑интенсивности.
- **SNN‑трекинг** (DTEASN, чисто спайковый), нейроморфные чипы **Loihi 2 / NorthPole** — трекинг
  на милливаттах.

**Релевантность:** прямой резонанс с нашим синтетическим event‑каналом λ̇ (наука проекта называла
event‑camera λ̇ как идеал). На тепловом сенсоре событий нет физически, но **event‑подобная
обработка** (изменения лог‑интенсивности) — дешёвый способ ловить движение малой цели с низкой
задержкой. Долгосрочно — гибрид тепловой кадр + event‑поведение. Источники:
[Sensors 2025: DVS‑driven SNN low‑power tracking](https://doi.org/10.3390/s25196048),
[USPTO: SNN target tracking via event camera](https://image-ppubs.uspto.gov/dirsearch-public/print/downloadPdf/12401885).

## §7. Пассивная дальнометрия по известному размеру — фронтир подтверждает нашу физику

Литература по монокулярной оценке глубины прямо формулирует нашу **§22‑ловушку**:

> «Из‑за неоднозначности между размером объекта и его дистанцией, оценка глубины по монокуляру —
> **математически некорректно поставленная (ill‑posed)** задача: одинаковый видимый размер даёт
> разные комбинации (размер × дальность).»

Это дословно наша «одна честная ловушка» `w=f·S·ρ` (одно уравнение, два неизвестных). SOTA‑ответы:
- **Depth Anything** (62M саморазмеченных сэмплов) — data‑driven общий приор глубины.
- **Object‑level monocular depth для БПЛА** и **per‑object distance с masked object modeling** —
  оценка дистанции именно для **детектированных объектов** (не плотная карта) — наш режим.

**Релевантность: подтверждающая и предостерегающая.** Deep‑монокуляр не отменяет неоднозначности —
он **вносит выученный приор размера**. Наш субтензный подход честнее: мы **знаем** класс → размер
S из идентичности, а неопределённость S несём раздельно (systematic∝R). Deep‑приор можно
использовать как **дополнительный** источник S(класс, ракурс) — ровно вход для GPR (V.4) и
RBPF (V.8). Источники:
[arXiv 2501.11841: survey monocular METRIC depth](https://arxiv.org/html/2501.11841v1),
[arXiv 2401.03191: per‑object distance masked object modeling](https://arxiv.org/pdf/2401.03191),
[arXiv 2302.08943: long‑range object‑level monocular depth for UAVs](https://arxiv.org/pdf/2302.08943),
[ACM CSUR: DL monocular depth survey](https://dl.acm.org/doi/10.1145/3677327).

## §8. Синтез: что фронтир говорит «взять» в 03‑fpv (и чего НЕ брать)

**Брать (несущее, подтверждено литературой):**
1. **InEKF / MEKF на SO(3)** для ego‑motion (§5) — консистентность + измерение скоса cam↔IMU.
2. **iBLF‑IGC для строапдауна с FOV** (§1.3) — готовая наука под наш планер/лаг/поле зрения.
3. **ZEM/t_go‑форма PN** (§1.1) с измеренной Vc из субтензы — честный апгрейд закона.
4. **Transformer/MI‑DETR ИК‑детект + дистилляция при point‑supervision** (§3.1) — под наш Y16 и
   дефицит меток; **motion‑integration** под движущуюся малую цель.
5. **Мультимодальная неопределённость (GSF/RBPF, диффузионный дух)** (§2.2) — под масштаб‑размер и манёвр.
6. **Робастная фильтрация (Student‑t)** + **вейвлет‑денойзинг** (§6.1) — под шум неохлаждаемого LWIR.
7. **Residual‑RL поверх PN** (§1.2) — робастность без потери доказуемого ядра.
8. **MARL‑сальво / консенсус t_go** (§1.4) — стратегический ответ на манёвренную цель.

**Не брать (не несущее для нашей задачи):** астродинамику/небесную механику/астронавигацию
(дальность < 1 км, орбит нет), радиолокацию (наш канал пассивный тепловой), релятивизм
(нерелятивистские скорости), гиперзвуковую аэрооптику (мы дозвуковые), охлаждаемый MWIR
(SWaP не тянем — сознательно на неохлаждаемом LWIR). Неевклидова/алгебраическая геометрия —
красивы, но не решают нашу физику; топология/дифгеометрия входят **только** через Ли‑группы
строапдауна (§5), и вот там они несущие.

**Главный вывод сбора:** фронтир **подтвердил** наш честный костяк (монокуляр ill‑posed →
субтенза по идентичности; строапдаун+FOV → iBLF‑IGC; строапдаун‑инерциалка → InEKF на Ли‑группе),
и указал конкретные, зрелые кирпичи, которыми его усилить, — без единого костыля и без «большой
науки не по адресу».
