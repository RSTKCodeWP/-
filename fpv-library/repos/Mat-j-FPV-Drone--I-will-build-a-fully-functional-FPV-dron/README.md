# Matěj's FPV Drone Build 🚀

My goal is to build a high-performance 5-inch freestyle FPV drone from scratch. I'm 14 years old and this is my first major hardware project where I'll be learning advanced soldering, electronics, and radio protocols.

## 🛠 Project Components
I have carefully selected these parts for the best price-to-performance ratio:

* **Frame:** Readytosky Mark4 5" (Carbon fiber)
* **Flight Controller & ESC (Stack):** SpeedyBee F405 V3/V4 (Supports mobile app configuration)
* **Motors:** EMAX ECO II 2207 (Durable and beginner-friendly)
* **Radio Link:** ELRS 2.4GHz (Open-source, long-range protocol)
* **Video System:** Analog 5.8GHz (Low latency for freestyle)
* **Controller:** RadioMaster Pocket (ELRS version)
* **Goggles:** Eachine EV800D (With DVR for flight recording)
