2. RASPBERRY PI REQUIRED PACKAGES
====================================================

----------------------------------------------------
Update Raspberry Pi
----------------------------------------------------

sudo apt update
sudo apt upgrade

----------------------------------------------------
Install Python3
----------------------------------------------------

sudo apt install python3
sudo apt install python3-pip

----------------------------------------------------
Install Serial Communication
----------------------------------------------------

pip3 install pyserial

Purpose:
Serial Communication with Arduino

----------------------------------------------------
Install MAVLink Support
----------------------------------------------------

pip3 install pymavlink

Purpose:
Drone Telemetry + MAVLink

----------------------------------------------------
Install OpenCV
----------------------------------------------------

pip3 install opencv-python

Purpose:
Video Processing

----------------------------------------------------
Install NumPy
----------------------------------------------------

pip3 install numpy

Purpose:
Math + Data Processing

----------------------------------------------------
Install Tkinter GUI
----------------------------------------------------

sudo apt install python3-tk

Purpose:
Ground Control GUI

----------------------------------------------------
Install Flask (Optional)
----------------------------------------------------

pip3 install flask

Purpose:
Web Dashboard

----------------------------------------------------
Install Folium Maps (Optional)
----------------------------------------------------

pip3 install folium

Purpose:
GPS Map Visualization
