UNBOUND - BUILD & DEPLOYMENT INSTRUCTIONS
==========================================

PREREQUISITES:
- Go 1.22+ (https://go.dev/dl/)
- Node.js 18+ & npm (https://nodejs.org/)
- Wails CLI v2 (go install github.com/wailsapp/wails/v2/cmd/wails@latest)

WINDOWS BUILD:
--------------
1. Install dependencies:
   cd clearflow/frontend
   npm install

2. Build desktop app:
   cd clearflow
   wails build

3. Output: clearflow/build/bin/Unbound.exe

4. For production release:
   wails build -clean -upx -ldflags "-w -s"

LINUX BUILD:
------------
1. Install system dependencies:
   sudo apt install libgtk-3-dev libwebkit2gtk-4.0-dev

2. Compile nfqws binary:
   git clone https://github.com/bol-van/zapret
   cd zapret/nfq
   sudo apt install libnetfilter-queue-dev libcap-dev
   make
   strip nfqws
   cp nfqws /path/to/clearflow/engine/core_bin/linux/

3. Build desktop app:
   cd clearflow/frontend
   npm install
   cd ..
   wails build

4. Output: clearflow/build/bin/Unbound

5. Run with sudo (required for iptables):
   sudo ./build/bin/Unbound

MACOS BUILD:
------------
1. Install Xcode Command Line Tools:
   xcode-select --install

2. Compile nfqws binary:
   git clone https://github.com/bol-van/zapret
   cd zapret/nfq
   make
   strip nfqws
   cp nfqws /path/to/clearflow/engine/core_bin/macos/

3. Build desktop app:
   cd clearflow/frontend
   npm install
   cd ..
   wails build

4. Output: clearflow/build/bin/Unbound.app

5. Run with sudo (required for pf):
   sudo ./build/bin/Unbound.app/Contents/MacOS/Unbound

ANDROID MODULE BUILD:
---------------------
1. Compile nfqws for Android:
   - Download Android NDK: https://developer.android.com/ndk/downloads
   - Follow instructions in BINARY_REQUIREMENTS.txt
   - Place binaries in clearflow/android/magisk/bin/

2. Create module ZIP:
   cd clearflow/android/magisk
   zip -r unbound_dpi_bypass_v2.4.0.zip . -x "*.git*" "README_ANDROID.txt"

3. Flash via Magisk/KernelSU Manager

DEVELOPMENT MODE:
-----------------
Run with live reload:
cd clearflow
wails dev

This starts:
- Go backend with hot reload
- Vite dev server on http://localhost:34115
- Desktop window with DevTools

CROSS-COMPILATION:
------------------
Windows from Linux:
  GOOS=windows GOARCH=amd64 wails build

Linux from macOS:
  GOOS=linux GOARCH=amd64 wails build

macOS from Linux (requires osxcross):
  GOOS=darwin GOARCH=amd64 wails build

TROUBLESHOOTING:
----------------
- "command not found: wails"
  → Add $GOPATH/bin to PATH: export PATH=$PATH:$(go env GOPATH)/bin

- "cannot find package" errors
  → Run: go mod tidy && go mod download

- Frontend build fails
  → Delete node_modules and package-lock.json, run npm install again

- Linux: "Operation not permitted" when starting
  → Run with sudo or add CAP_NET_ADMIN capability:
    sudo setcap cap_net_admin+ep ./build/bin/Unbound

- macOS: "App is damaged and can't be opened"
  → Remove quarantine: xattr -cr Unbound.app
