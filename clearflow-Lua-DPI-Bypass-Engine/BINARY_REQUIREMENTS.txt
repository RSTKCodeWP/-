UNBOUND - BINARY REQUIREMENTS
==============================

WINDOWS (clearflow/engine/core_bin/windows/):
✓ winws2.exe         - Zapret2 Windows binary (WinDivert-based)
✓ goodbyedpi.exe     - GoodbyeDPI Windows binary
✓ WinDivert.dll      - WinDivert driver library
✓ WinDivert64.sys    - WinDivert kernel driver
✓ cygwin1.dll        - Cygwin runtime (if needed by binaries)
✓ ip2net.exe         - IP network utilities
✓ mdig.exe           - DNS query tool
✓ killall.exe        - Process termination utility

LINUX (clearflow/engine/core_bin/linux/):
⚠ nfqws              - Zapret nfqws binary (x86_64)
  Source: https://github.com/bol-van/zapret
  Compile: cd zapret/nfq && make
  Dependencies: libnetfilter_queue, libcap

MACOS (clearflow/engine/core_bin/macos/):
⚠ nfqws              - Zapret nfqws binary (x86_64 + arm64 universal)
  Source: https://github.com/bol-van/zapret
  Compile: cd zapret/nfq && make (requires Xcode/Command Line Tools)
  Note: macOS uses divert sockets, not NFQUEUE

ANDROID (clearflow/android/magisk/bin/):
⚠ nfqws_arm64        - Zapret nfqws for ARM64 (aarch64)
⚠ nfqws_arm          - Zapret nfqws for ARMv7 (armeabi-v7a)
  Source: https://github.com/bol-van/zapret
  Compile: Use Android NDK cross-compilation
  
  Example NDK build:
  export NDK=/path/to/android-ndk
  export TOOLCHAIN=$NDK/toolchains/llvm/prebuilt/linux-x86_64
  export CC=$TOOLCHAIN/bin/aarch64-linux-android29-clang
  cd zapret/nfq && make

LUA SCRIPTS (clearflow/engine/lua_scripts/):
✓ zapret-lib.lua     - Core Lua library
✓ zapret-antidpi.lua - Anti-DPI strategies
✓ zapret-obfs.lua    - Obfuscation methods
✓ zapret-pcap.lua    - Packet capture utilities
✓ zapret-tests.lua   - Testing framework
✓ zapret-auto.lua    - Auto-detection logic

COMPILATION NOTES:
==================

LINUX nfqws:
  sudo apt install libnetfilter-queue-dev libcap-dev
  git clone https://github.com/bol-van/zapret
  cd zapret/nfq
  make
  strip nfqws
  cp nfqws /path/to/clearflow/engine/core_bin/linux/

MACOS nfqws:
  brew install libnetfilter-queue (via custom tap if available)
  git clone https://github.com/bol-van/zapret
  cd zapret/nfq
  make
  strip nfqws
  lipo -create nfqws_x86_64 nfqws_arm64 -output nfqws (for universal binary)
  cp nfqws /path/to/clearflow/engine/core_bin/macos/

ANDROID nfqws:
  Download Android NDK: https://developer.android.com/ndk/downloads
  
  For ARM64:
  export NDK=/path/to/android-ndk
  export TOOLCHAIN=$NDK/toolchains/llvm/prebuilt/linux-x86_64
  export CC=$TOOLCHAIN/bin/aarch64-linux-android29-clang
  export SYSROOT=$TOOLCHAIN/sysroot
  cd zapret/nfq
  make clean && make
  $TOOLCHAIN/bin/llvm-strip nfqws
  cp nfqws /path/to/clearflow/android/magisk/bin/nfqws_arm64
  
  For ARMv7:
  export CC=$TOOLCHAIN/bin/armv7a-linux-androideabi29-clang
  make clean && make
  $TOOLCHAIN/bin/llvm-strip nfqws
  cp nfqws /path/to/clearflow/android/magisk/bin/nfqws_arm
