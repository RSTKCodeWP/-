# Changelog

All notable changes to MaixCAM WildTrap will be documented in this file.

---

## [1.6.0] - 2026-05-11
### ✨ Added
- **Gallery Mode**: View captures directly on the camera touchscreen with navigation.
- **External Trigger**: Support for a second GPIO output (Light/Alarm) with configurable pin and duration.
- **UI Expansion**: Settings menu now has 3 pages to accommodate new features.
### 🔧 Changed
- VERSION updated to 1.6.0.

## [1.5.0] - 2026-05-11
### ✨ Added
- **Servo Control**: Integrated physical trigger system via PWM.
- **Advanced UI**: Multi-page touchscreen settings menu.
- **OSD Toggle**: Option to hide overlay on live preview.
- **Quick Reset**: Factory reset button in UI.
### 🔧 Changed
- Reorganized repository structure into `src/` and `docs/`.

## [1.0.0] - 2026-05-11
### 🎉 Initial Release
- AI-powered camera trap with YOLOv8 and Motion detection.
