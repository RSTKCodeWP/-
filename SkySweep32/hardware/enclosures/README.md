# SkySweep32 Pro — Корпус Sentinel (STL файлы)

Профессиональный корпус для **Pro Tier** платы (120×80мм).  
Стиль: **Sentinel** — промышленный стационарный блок, согласно `docs/en/enclosures.md`.

---

| Файл | Описание |

## Особенности конструкции

### Нижняя часть (`case_bottom.stl`)
- **4× монтажные стойки M3** — совпадают с отверстиями на PCB (5×5, 115×5, 5×75, 115×75 мм)
- **Вырез под USB** — левая стенка, выровнен под разъём ESP32
- **8× вентиляционных щели** — задняя стенка, 30×2.5 мм каждая, для охлаждения RX5808 и ESP32
- **2× монтажных ушка (wing brackets)** — по бокам, для крепления на мачту или стену через U-болт или стяжку
- **4× угловых босса M3** — крепёж крышки к нижней части

### Верхняя крышка (`case_lid.stl`)
- **Вырез под OLED 0.96"** — 26×14 мм с ободком (OLED стекло укладывается в паз)
- **3× вентиляционных щели** — над зоной GPS/LoRa
- **Отверстие под GPS антенну** — Ø9 мм, для кабеля внешней патч-антенны
- **4× SMA отверстия** — правая стенка корпуса, Ø6.5 мм:
  - 900 МГц (CC1101)
  - 2.4 ГГц (NRF24L01+)
  - 5.8 ГГц (RX5808)
  - 915 МГц (LoRa SX1276)
- **4× сквозных отверстия M3** — для соединения с нижней частью

## Сборка корпуса

### Необходимые крепёжные материалы
- **4× M3 brass heat-set inserts** (M3×4мм) — в стойки нижней части
- **4× M3×10мм винты** — крышка к нижней части
- **4× SMA bulkhead connectors** (panel-mount) с гайками
- **4× SMA кабели** (pigtail) — от разъёмов на плате до панельных SMA

### Порядок сборки
1. Запрессуйте **M3 heat-set inserts** в монтажные стойки (паяльником ~200°C, аккуратно)
2. Установите **SMA panel-mount разъёмы** в отверстия правой стенки крышки, затяните гайки
3. Положите плату в нижнюю часть, совместите монтажные отверстия
4. Закрепите плату **M3×6мм** винтами через PCB в стойки
5. Подключите **SMA pigtail кабели** от платы к панельным разъёмам
6. Проденьте **USB кабель** через вырез в левой стенке (или используйте удлинитель)
7. Закройте **крышку** и затяните **4× M3×10мм** винта по углам
8. Установите **OLED дисплей** снизу в паз крышки (держится на защёлке)

## Регенерация STL

Если нужно изменить размеры или добавить вырезы:

```bash
# Требует FreeCAD 1.0+
FreeCADCmd.exe hardware/enclosures/build_case.py
```

Изменяемые параметры в скрипте (`build_case.py`):
- `WALL` — толщина стенок
- `FLOOR` / `LID` — толщина дна/крышки
- `COMP_H` — высота для компонентов (увеличить если нужно больше места)
- `sma_ys` — Y-координаты SMA отверстий
